# 🐇 Rabbit Store

Rabbit Store is a full-featured **eCommerce web application** built using the **MERN stack** (MongoDB, Express, React, Node.js).  
It offers a seamless shopping experience for men’s and women’s clothing, complete with authentication, cart management, payments, and admin control.

---

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT) + Cookies
- **Payments:** PayPal API
- **Deployment:** [Vercel]
- 🌐 **Live Demo:** [Click here](https://rabbit-market-uxr9.vercel.app/)

---

## Features

### Customer Features

- Browse men’s and women’s clothing collections
- Filter products by **brand, material, gender**, and more
- View product details and add items to the shopping cart
- Checkout securely and make payments using **PayPal**
- Persistent login using **JWT authentication**

### Admin Features

- Full-featured **Admin Panel**
  - Add, edit, or remove products
  - Track ordered products and change states manually
  - Manage users (add or remove)
  - Monitor sales and revenue
- Secure routes accessible only to admins

## ⚙️ Installation & Setup

1, Clone the repository:

```bash
git clone https://github.com/Wondirad-Kifelew/Rabbit-market.git
cd Rabbit-market
```

2, Backend setup

```bash
cd backend
npm install
npm run dev
```

3, Front end setup

```bash
cd frontend
npm install
npm run dev
```
